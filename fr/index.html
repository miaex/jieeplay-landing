Pratique

Garde JieePlay à portée de main.

JieePlay fonctionne directement sur ton téléphone. Tu pourras l'ajouter à ton écran d'accueil pour retrouver facilement ton aventure.

  1. Ouvre JieePlay avec Chrome.
  2. Ouvre le menu ⋮.
  3. Choisis "Ajouter à l'écran d'accueil" ou "Installer l'application".
  4. Confirme.
  1. Ouvre JieePlay avec Safari.
  2. Appuie sur le bouton Partager.
  3. Choisis "Sur l'écran d'accueil".
  4. Appuie sur "Ajouter".
