À faire une fois dans le jeu

Installer JieePlay

01 Sur Android
1
Ouvre le menu

Une fois le jeu ouvert dans ton navigateur, appuie sur les trois points ⋮.

2
Choisis l'installation

Appuie sur « Installer l'application » ou « Ajouter à l'écran d'accueil ».

3
Confirme

Valide l'installation. Le jeu sera alors accessible directement depuis ton écran d'accueil.

02 Sur iPhone / iPad
1
Ouvre le menu Partager

Une fois le jeu ouvert dans Safari, appuie sur le bouton Partager.

2
Ajoute à l'écran d'accueil

Fais défiler les options puis choisis « Sur l'écran d'accueil ».

3
Appuie sur Ajouter

Confirme. L'icône du jeu sera alors accessible directement depuis ton écran d'accueil.

Les intitulés peuvent légèrement varier selon le navigateur et sa version.
